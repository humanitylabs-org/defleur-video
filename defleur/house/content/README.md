# Rendered video content, not Wizard interface chrome

This directory contains production 1080×1920 composition assets and immutable historical visual references. Its fonts, literal approved colors and fixed pixel geometry are part of the video export contract. They intentionally do not inherit the containing Wizard shell skin.

The canonical Wizard style gate excludes `content` directories for this class of non-interface media. This placement is not an app UI exception: no app window, control, composer or theme transport is implemented here. Browser execution is solely the existing deterministic native video frame-capture workflow.

Historical source compositions remain byte-identical to the approved branch artifacts; current compositions compile from the typed app-owned house plan.
